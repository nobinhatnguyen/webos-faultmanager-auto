1. Kiểm tra điều kiện và khả năng root

1.1. Phạm vi của faultmanager-autoroot

Công cụ gốc được phát triển bởi throwaway96; tài liệu này sử dụng bản được chia sẻ tại GitHub của Nobi Nhật Nguyễn. Dự án gốc throwaway96/faultmanager-autoroot khai thác lỗ hổng dịch vụ faultmanager do buglloc phát hiện, tự động root và cài Homebrew Channel.

  • Công cụ hướng tới webOS 4.0–10.0 nếu firmware vẫn còn lỗ hổng.
  • Dịch vụ có mặt từ webOS 3.5 nhưng script này không hoạt động trên 3.5. Tác giả gợi ý xem dejavuln-autoroot cho trường hợp đó.
  • Theo thông tin tác giả công bố ngày 24/08/2025, đa số firmware mới của webOS 5/6/7/9 đã vá; bản cập nhật webOS 10.1+ đã vá lỗ hổng được mô tả.
  • Phiên bản webOS không đủ để kết luận: phải kiểm tra cả model và firmware cụ thể tại CanI.RootMy.TV.
  • Không đổi NSU Mode trong menu Instart để tìm firmware thử nghiệm.

Điểm dừng bắt buộc: Nếu CanI.RootMy.TV không xác nhận firmware phù hợp hoặc thông tin chưa rõ, không chạy script. Không tự thêm --skip-version-check chỉ để vượt cảnh báo.

1.2. Chuẩn bị

  • TV LG và máy tính cùng mạng LAN/Wi-Fi, không bật AP/client isolation.
  • Biết IP của TV, ví dụ 192.168.1.100.
  • Tài khoản LG Developer, ứng dụng Developer Mode trên TV.
  • Mac có Terminal hoặc Windows 10/11 có PowerShell và OpenSSH Client.
  • Có quyền cài đặt/điều khiển TV; nguồn điện và kết nối ổn định.

2. Chuẩn bị mạng

Trên TV: Settings → All Settings → Network (đường dẫn thay đổi theo đời TV) → xem địa chỉ IP. Trong ví dụ: 192.168.1.100.

macOS — Terminal:

ping -c 4 192.168.1.100

Windows — PowerShell:

ping -n 4 192.168.1.100

Không phản hồi ping không luôn có nghĩa SSH bị chặn: một số thiết bị chặn ICMP. Có thể thử TCP sau khi bật Key Server:

# Windows
Test-NetConnection 192.168.1.100 -Port 9922

# macOS
nc -vz 192.168.1.100 9922

3. Bật LG Developer Mode

  1. Vào LG webOS TV Developer, tạo/đăng nhập tài khoản LG Developer.
  2. Trên TV mở LG Apps/Content Store, tìm Developer Mode chính thức của LG và cài.
  3. Mở app, đăng nhập, bật Dev Mode Status = ON. Khởi động lại TV nếu được yêu cầu.
  4. Mở lại app, bật Key Server = ON.
  5. Ghi lại IP Address và Passphrase hiển thị trên TV. Không chia sẻ passphrase; chỉ nhập vào Terminal/PowerShell khi cần.

Phân biệt: webos_rsa là SSH private key được Key Server cung cấp. Passphrase dùng để mở khóa private key. Chúng không phải mật khẩu tài khoản LG và không phải mật khẩu SSH root sau này.

4. Kết nối SSH Developer Mode — macOS & Windows

Chọn tab macOS hoặc Windows ở mỗi bước. Tất cả lệnh đều chạy trên máy tính, không chạy trên TV. Trước tiên hãy bật Developer Mode và Key Server trên TV.

4.1. Kiểm tra công cụ SSH

Kiểm tra SSH
ssh -V
ssh -V

Nếu Windows báo không tìm thấy ssh, cài OpenSSH Client tại Settings → Apps → Optional features. Trên macOS, SSH thường đã có sẵn.

4.2. Tải private key từ Key Server của TV

Tải webos_rsa
mkdir -p ~/.ssh
curl -fL 'http://192.168.1.100:9991/webos_rsa' -o ~/.ssh/webos_rsa
chmod 600 ~/.ssh/webos_rsa
ls -l ~/.ssh/webos_rsa
New-Item -ItemType Directory -Force "$env:USERPROFILE\.ssh" | Out-Null
Invoke-WebRequest -Uri 'http://192.168.1.100:9991/webos_rsa' -OutFile "$env:USERPROFILE\.ssh\webos_rsa"

Private key phải được bảo mật, không gửi lên GitHub hoặc cho AI. Nếu tải không được, kiểm tra IP và trạng thái Key Server = ON.

4.3. Thiết lập quyền truy cập private key

Giới hạn quyền key
chmod 600 ~/.ssh/webos_rsa
ls -l ~/.ssh/webos_rsa
$key = "$env:USERPROFILE\.ssh\webos_rsa"
icacls $key /inheritance:r
icacls $key /grant:r "${env:USERNAME}:R"
icacls $key

Trên Windows, nếu OpenSSH vẫn báo quyền file quá rộng, kiểm tra danh sách ACL trước khi chỉnh sửa tiếp. Trên macOS, quyền thông thường là -rw-------.

4.4. Kết nối SSH Developer Mode (port 9922)

Kết nối prisoner@TV
ssh -T \
  -o HostKeyAlgorithms=+ssh-rsa \
  -o PubkeyAcceptedAlgorithms=+ssh-rsa \
  -i ~/.ssh/webos_rsa \
  -p 9922 prisoner@192.168.1.100 'id; uname -a' 
ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa -i "$env:USERPROFILE\.ssh\webos_rsa" -p 9922 prisoner@192.168.1.100 'id; uname -a'

Nhập passphrase đang hiển thị trong ứng dụng Developer Mode trên TV khi SSH yêu cầu. -T tránh lỗi PTY trên một số TV. Chỉ dùng ngoại lệ ssh-rsa cho kết nối TV cũ, không bật cho mọi SSH host.

Thành công: TV trả về thông tin id và uname -a. Sau đó chuyển sang bước tiếp theo để đưa autoroot.sh vào TV.

5. Chuyển autoroot.sh sang TV

Cách A — tải trực tiếp trên TV (nếu curl khả dụng)

Thực thi từ Mac:

ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa \
  -i ~/.ssh/webos_rsa -p 9922 prisoner@192.168.1.100 \
  'curl -fL -o /tmp/autoroot.sh https://raw.githubusercontent.com/nobinhatnguyen/faultmanager-autoroot/refs/heads/main/autoroot.sh && ls -l /tmp/autoroot.sh'

Từ Windows PowerShell:

ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa -i "$env:USERPROFILE\.ssh\webos_rsa" -p 9922 prisoner@192.168.1.100 'curl -fL -o /tmp/autoroot.sh https://raw.githubusercontent.com/nobinhatnguyen/faultmanager-autoroot/refs/heads/main/autoroot.sh && ls -l /tmp/autoroot.sh'

URL main có thể thay đổi nội dung. Để tái lập và kiểm toán, ưu tiên tải bản phát hành/commit cụ thể, kiểm tra script trước khi chạy. Nếu TV không có curl, dùng cách B.

Cách B — chuyển nội dung qua SSH cat (không cần scp trên TV)

Một số LG TV không có scp phía server (sh: scp: not found). Cách sau dùng SSH standard input.

macOS — mặc định file ở thư mục Downloads:

ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa \
  -i ~/.ssh/webos_rsa -p 9922 prisoner@192.168.1.100 \
  'cat > /tmp/autoroot.sh' \
  < ~/Downloads/autoroot.sh

Windows PowerShell — mặc định file ở thư mục Downloads:

# File autoroot.sh nằm trong thư mục Downloads của người dùng hiện tại
$scriptPath = "$env:USERPROFILE\Downloads\autoroot.sh"
# Dùng cmd /c để chuyển byte trực tiếp qua stdin, tránh pipeline PowerShell đổi encoding
cmd /c "ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa -i `"%USERPROFILE%\.ssh\webos_rsa`" -p 9922 prisoner@192.168.1.100 `"cat > /tmp/autoroot.sh`" < `"$scriptPath`""

Nếu cách Windows trên gặp lỗi quoting, lựa chọn đơn giản hơn là dùng SFTP nếu TV có SFTP subsystem, hoặc chạy lệnh tải trực tiếp trên TV (cách A). Không dùng Get-Content | ssh cho file nhị phân vì có thể thay đổi byte.

Kiểm tra file trên TV (macOS):

ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa \
  -i ~/.ssh/webos_rsa -p 9922 prisoner@192.168.1.100 \
  'ls -lh /tmp/autoroot.sh; head -n 5 /tmp/autoroot.sh'

Windows: dùng lệnh SSH tương tự ở mục 5.3, thay 'id; uname -a' bằng 'ls -lh /tmp/autoroot.sh; head -n 5 /tmp/autoroot.sh'.

6. Chạy faultmanager-autoroot

Chỉ chạy khi đã xác minh firmware tại CanI.RootMy.TV. Lệnh chạy từ Mac:

ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa \
  -i ~/.ssh/webos_rsa -p 9922 prisoner@192.168.1.100 \
  'sh /tmp/autoroot.sh'

Windows PowerShell:

ssh -T -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedAlgorithms=+ssh-rsa -i "$env:USERPROFILE\.ssh\webos_rsa" -p 9922 prisoner@192.168.1.100 'sh /tmp/autoroot.sh'

Chờ thông báo Payload complete và script thoát. Script có thể chủ động gây segmentation fault để kích hoạt lỗ hổng; đó là hành vi được mô tả trong mã, không tự nó chứng minh root thành công. Xem log/Root status để xác nhận. Không rút điện hoặc ngắt mạng giữa quá trình.

Tùy chọn của script:

Tùy chọn Tác dụng
-d, --debug Ghi log chi tiết hơn
-t, --telnet Mở root telnet port 23; không khuyến nghị vì không mã hóa; không có telnetd trên webOS 9 theo tác giả
--leave-script Không đổi tên start-devmode.sh khi chữ ký không hợp lệ; trường hợp đặc biệt

Nếu có hbchannel.ipk cùng thư mục script, nó được sử dụng; nếu không, script tải IPK Homebrew Channel theo URL được khai báo trong bản script. Đừng mặc định đó luôn là bản mới nhất; ví dụ file đã cung cấp trong hội thoại ghim URL Homebrew Channel v0.7.3.

7. Homebrew Channel và gỡ Developer Mode

  1. Xác nhận script kết thúc và Homebrew Channel đã được cài/elevated.
  2. Mở Homebrew Channel → Settings, xác nhận trạng thái root (ok hoặc trạng thái tương đương theo phiên bản).
  3. Theo hướng dẫn tác giả faultmanager-autoroot: phải gỡ ứng dụng LG Developer Mode trước khi reboot sau khi root thành công. Không cài lại Developer Mode khi TV đang rooted.
  4. Để tránh mất đường quản trị, nên cấu hình SSH root độc lập ngay khi có thể; nếu việc kích hoạt SSH yêu cầu reboot, kiểm tra kỹ tài liệu và trạng thái hiện tại trước khi reboot.

Không được hiểu “đã thấy icon Homebrew Channel” là chắc chắn đã có root. Nếu trạng thái root chưa rõ, dừng lại và kiểm tra trước khi gỡ app/reboot.

8. Thiết lập SSH root độc lập với Developer Mode

Trong Homebrew Channel → Settings, tìm và bật SSH Server (nếu tùy chọn có trong phiên bản đã cài). Trên các cấu hình webOS Homebrew thường dùng SSH port 22, user root; kiểm tra lại trên TV vì cách triển khai có thể khác. Nếu root SSH đã chạy, thử từ máy tính:

macOS:

ssh root@192.168.1.100

Windows PowerShell:

ssh root@192.168.1.100

Nếu SSH hỏi mật khẩu mà bạn chưa từng đặt, một số bản Homebrew/Dropbear từng dùng mặc định alpine. Chỉ thử nếu tài liệu đúng với bản đang dùng; đổi sang key authentication ngay và không để mật khẩu mặc định lâu dài. Nếu không đúng, kiểm tra hướng dẫn Homebrew của phiên bản hiện tại, không thử mật khẩu hàng loạt.

Sau khi đăng nhập, kiểm tra trên TV:

id
whoami
uname -a

uid=0(root) xác nhận phiên shell đó có quyền root. Kiểm tra kết nối root sau reboot để xác nhận SSH Server tự khởi động, không chỉ chạy tạm thời.

9. SSH root bằng key; bỏ passphrase nếu cần

10.1. Tạo key riêng trên Mac

ssh-keygen -t ed25519 -f ~/.ssh/lg_tv_root -C 'lg-tv-root'
chmod 600 ~/.ssh/lg_tv_root

Tạo trên Windows PowerShell:

ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\lg_tv_root" -C 'lg-tv-root'

Giữ bí mật file private key lg_tv_root; chỉ copy public key lg_tv_root.pub vào TV.

10.2. Cài public key lên TV

macOS (chạy trên Mac, KHÔNG chạy trong prompt root@LGwebOSTV):

cat ~/.ssh/lg_tv_root.pub | ssh root@192.168.1.100 \
  'umask 077; mkdir -p /home/root/.ssh; cat >> /home/root/.ssh/authorized_keys; chmod 700 /home/root/.ssh; chmod 600 /home/root/.ssh/authorized_keys'

Windows PowerShell:

Get-Content -Raw "$env:USERPROFILE\.ssh\lg_tv_root.pub" | ssh root@192.168.1.100 'umask 077; mkdir -p /home/root/.ssh; cat >> /home/root/.ssh/authorized_keys; chmod 700 /home/root/.ssh; chmod 600 /home/root/.ssh/authorized_keys'

Đường dẫn /home/root là trường hợp thường gặp trên webOS; nếu home thực tế khác, kiểm tra echo "$HOME" trên shell root và thay cho phù hợp.

macOS kiểm tra key:

ssh -o PasswordAuthentication=no -o KbdInteractiveAuthentication=no \
  -i ~/.ssh/lg_tv_root root@192.168.1.100 'id'

Windows kiểm tra key:

ssh -o PasswordAuthentication=no -o KbdInteractiveAuthentication=no -i "$env:USERPROFILE\.ssh\lg_tv_root" root@192.168.1.100 'id'

Nếu hiện uid=0(root) mà không hỏi mật khẩu TV, key hoạt động. Nếu key có passphrase, SSH vẫn có thể hỏi passphrase của key; đó là hai loại thông tin khác nhau.

10.3. Gỡ passphrase khỏi key (tùy chọn)

macOS:

ssh-keygen -p -f ~/.ssh/lg_tv_root

Windows:

ssh-keygen -p -f "$env:USERPROFILE\.ssh\lg_tv_root"

Nhập passphrase cũ, rồi Enter hai lần ở câu hỏi passphrase mới để để trống. Việc này không thay đổi public key đã cài trên TV. Đánh đổi bảo mật: private key không còn được mã hóa bằng passphrase. Nếu muốn thuận tiện mà vẫn bảo mật, cân nhắc giữ passphrase và dùng SSH agent.

10.4. Tạo alias ssh lgtv

macOS: mở nano ~/.ssh/config và thêm:

Host lgtv
    HostName 192.168.1.100
    User root
    Port 22
    IdentityFile ~/.ssh/lg_tv_root
    IdentitiesOnly yes

Windows: mở file %USERPROFILE%\.ssh\config bằng Notepad và thêm:

Host lgtv
    HostName 192.168.1.100
    User root
    Port 22
    IdentityFile ~/.ssh/lg_tv_root
    IdentitiesOnly yes

Trong Windows OpenSSH, ~/.ssh/lg_tv_root thường được mở rộng thành thư mục người dùng. Nếu không nhận, thay bằng đường dẫn tuyệt đối dùng dấu /, ví dụ ~/.ssh/lg_tv_root.

Cả hai hệ điều hành:

ssh lgtv
ssh lgtv 'id; uname -a'

10. Telemetry, cập nhật firmware và bảo mật

11.1. Trong Homebrew Channel

Nếu Homebrew Channel phiên bản của bạn có các tùy chọn tương ứng, có thể bật Disable telemetry và Block system updates theo mục đích. Tên và hiệu lực có thể khác theo bản phát hành. Chỉ bật sau khi đã kiểm tra Root status và hiểu tác động.

11.2. Trong menu TV

Tìm Settings → All Settings → Support → Software Update (hoặc menu tương ứng) và tắt Automatic Updates nếu muốn tránh cập nhật ngoài ý muốn.

Giới hạn cần hiểu:

  • “Disable telemetry” không bảo đảm ngăn mọi dữ liệu rời TV.
  • “Block system updates” không đồng nghĩa chặn mọi cơ chế cập nhật; cập nhật thủ công vẫn có thể xảy ra.
  • Chặn cập nhật kéo dài làm TV thiếu bản vá bảo mật. Cân nhắc tách TV khỏi mạng khách/thiết bị nhạy cảm và chỉ cho phép truy cập SSH từ LAN tin cậy.
  • Không mở port SSH 22 hoặc telnet 23 ra Internet; không dùng port-forward từ router.
  • Kiểm tra SSH root hoạt động sau reboot trước khi xem cấu hình hoàn tất.

11. Claude Code và quy trình phát triển ứng dụng

Topic 2 (điều chỉnh) sử dụng Claude Code trên máy tính để hỗ trợ kiểm tra, tối ưu hoặc build ứng dụng. Đây là công cụ tùy chọn, không phải thành phần bắt buộc để bật Developer Mode, SSH hay root.

Cài đặt và sử dụng Claude Code (macOS / Windows)

Claude Code là trợ lý lập trình chạy trên máy tính; không cài Claude Code trực tiếp trên TV. Xem hướng dẫn cài đặt mới nhất tại Claude Code Setup. Sau khi cài theo hướng dẫn chính thức, mở Terminal (macOS) hoặc PowerShell (Windows) và kiểm tra:

claude --version

Chuyển tới thư mục dự án trên máy tính và mở Claude Code:

macOS:

cd ~/Downloads
claude

Windows PowerShell (ví dụ, thay bằng thư mục dự án thực tế):

cd "$env:USERPROFILE\Downloads"
claude

Đăng nhập theo hướng dẫn hiển thị. Khi làm việc với TV, có thể yêu cầu Claude Code đề xuất lệnh SSH, kiểm tra thông tin hệ thống hoặc hướng dẫn build IPK; xem kỹ lệnh trước khi cho phép chạy. Không dán passphrase, mật khẩu root hoặc nội dung private key vào prompt.

12.1. Nguyên tắc an toàn

  • Tải công cụ từ nguồn chính thức; xác minh ứng dụng và quyền truy cập trước khi đăng nhập.
  • Chỉ cung cấp IP TV, model, phiên bản firmware, mục tiêu công việc cho AI khi cần.
  • Không gửi passphrase Developer Mode, private key, mật khẩu root vào chat hoặc prompt. Tự nhập vào terminal/credential manager cục bộ.
  • Chỉ cho AI thực hiện lệnh sau khi bạn xem và chấp thuận, đặc biệt với rm, thay đổi dịch vụ, cập nhật firmware và root.

12.2. Hai luồng công việc

A — Tối ưu hệ thống TV: kiểm tra dịch vụ, sử dụng bộ nhớ, các tùy chọn giao diện/telemetry và cập nhật. “Dọn RAM” không phải lúc nào cũng làm TV nhanh hơn; không xóa dịch vụ hệ thống khi chưa hiểu chức năng. Chặn quảng cáo YouTube phụ thuộc ứng dụng và giải pháp hợp lệ, không phải tính năng mặc định của SSH/root.

B — Phát triển ứng dụng: chuẩn bị source, xác định loại app webOS, build .ipk theo SDK, cài bằng công cụ phát triển hoặc Homebrew phù hợp, xem log, thử nghiệm trên TV. Root không bắt buộc cho đa số ứng dụng webOS thông thường; ưu tiên Developer Mode và SDK chính thức trong quy trình phát triển tiêu chuẩn.

Ví dụ lệnh chỉ kiểm tra từ Mac/Windows khi đã cấu hình alias:

ssh lgtv 'id; uname -a; df -h'

Để cài app, cần biết mã nguồn, framework, SDK và phương thức đóng gói; không tự đoán lệnh cài một file .ipk chưa xác định.

13. Checklist cuối cùng

  • Đã kiểm tra model/firmware tại CanI.RootMy.TV.
  • TV và máy tính cùng mạng, biết IP TV.
  • Developer Mode và Key Server hoạt động trước khi root.
  • Kết nối prisoner port 9922 thành công.
  • autoroot.sh được đặt trên TV và chạy đúng môi trường.
  • Có Payload complete, xác nhận root/elevation trong Homebrew.
  • Gỡ Developer Mode trước reboot theo hướng dẫn faultmanager-autoroot.
  • SSH root port 22 hoạt động và đã cài public key.
  • Đăng nhập root bằng key được sau reboot, không phụ thuộc Developer Mode.
  • Đã đánh giá telemetry/cập nhật và rủi ro bảo mật.
  • Không chia sẻ key, passphrase, mật khẩu; không mở SSH ra Internet.
  • Đã dọn và tối ưu TV bằng tvopt trước khi cài launcher (mục 14).

14. Dọn và tối ưu TV trước khi cài launcher

Ngay sau khi bật, TV LG thường đã nạp sẵn YouTube, Netflix, AirPlay ở nền và gọi về máy chủ quảng cáo. Dọn trước khi cài launcher để launcher có thêm RAM và để dễ biết lỗi (nếu có) đến từ đâu. Trên TV đã thử (UK6340PTF, webOS TV Lite 4.4.3), RAM khả dụng sau khi bật tăng từ khoảng 145 MB lên 340 MB.

Bước 1 — Tắt các mục không cần trong Cài đặt của TV

Không cần root. Tối thiểu: tắt Quick Start+, Home Promotion, Content Recommendation, Live Plus, bỏ đồng ý quảng cáo trong User Agreements, tắt AirPlay nếu không dùng. Danh sách đủ 10 mục kèm đường dẫn menu: tv-optimize › Phần A.

Bước 2 — Chạy tvopt bằng SSH root

Script tvopt.sh (thư mục tv-optimize của repo) chạy thẳng trên TV và tự chạy lại mỗi lần bật TV: chặn tên miền quảng cáo LG, chặn cập nhật firmware, tắt telnet root không mật khẩu, tắt AirPlay/HomeKit, đóng Netflix/YouTube nạp sẵn ở nền. Script không đóng app đang xem và không ghi vào phân vùng hệ thống. Tải tvopt.sh vào thư mục Downloads, rồi chạy trên máy tính:

macOS:

cd ~/Downloads
ssh root@192.168.1.100 "tr -d '\r' > /tmp/tvopt.sh" < tvopt.sh
ssh root@192.168.1.100 sh /tmp/tvopt.sh install

Windows PowerShell:

cd "$env:USERPROFILE\Downloads"
cmd /c "ssh root@192.168.1.100 `"tr -d '\r' > /tmp/tvopt.sh`" < tvopt.sh"
ssh root@192.168.1.100 sh /tmp/tvopt.sh install

Bước 3 — Kiểm tra

ssh root@192.168.1.100 sh /home/root/tvopt/tvopt.sh status

Kết quả hiện từng mục đang bật hay tắt, app đang chạy và RAM khả dụng. Đổi cấu hình, gỡ cài đặt, danh sách tên miền không nên chặn: xem hướng dẫn tvopt đầy đủ. Gỡ nhanh: sh /home/root/tvopt/tvopt.sh uninstall rồi khởi động lại TV.

15. Hướng dẫn mở rộng: Cài launcher Luma

Luma là launcher native dành cho LG webOS TV đã root, có giao diện lấy cảm hứng từ Apple TV. Đây là bước tùy chọn sau khi đã hoàn tất root, SSH và dọn TV, không phải một công cụ root. Xem dự án lg-luma trên GitHub.

Trước khi cài: TV cần root hoạt động, Homebrew Channel ở trạng thái elevated và kết nối mạng ổn định. Luma dự kiến chạy trên webOS 4 trở lên, nhưng khả năng thay thế màn hình Home khác nhau theo phiên bản/model. Không bật Home takeover nếu thiết bị chưa được hỗ trợ.

Bước 1 — Kiểm tra SSH root

Chạy lệnh trên máy tính. Nếu đã cấu hình alias lgtv, bạn có thể thay root@192.168.1.100 bằng lgtv.

ssh root@192.168.1.100 'id; uname -a'
ssh root@192.168.1.100 'id; uname -a'

Kết quả uid=0(root) xác nhận quyền root của phiên SSH. Mở Homebrew Channel trên TV và kiểm tra Root status trước khi tiếp tục.

Bước 2 — Cài Luma qua Homebrew Channel (khuyến nghị)

  1. Trên TV, mở Homebrew Channel.
  2. Vào mục quản lý kho ứng dụng (Repositories / Add repository; tên có thể khác theo phiên bản).
  3. Thêm địa chỉ repository chính thức bên dưới.
  4. Làm mới danh sách ứng dụng, tìm Luma rồi chọn Install.
  5. Mở Luma từ danh sách ứng dụng trên TV và kiểm tra launcher hoạt động bình thường trước khi thay Home.
https://github.com/ecklf/lg-luma/releases/latest/download/repo.json

Đây là địa chỉ repository do chính dự án Luma công bố, không phải lệnh Terminal.

Bước 3 — Cài bằng SSH nếu không dùng repository (tùy chọn)

Tải file .ipk phù hợp từ GitHub Releases của Luma về máy tính. Đổi tên file đã tải thành luma.ipk và đặt trong thư mục Downloads. Không giả định số phiên bản trong tên file vì các bản phát hành có thể thay đổi.

scp -O ~/Downloads/luma.ipk root@192.168.1.100:/tmp/luma.ipk
ssh root@192.168.1.100
scp -O "$env:USERPROFILE\Downloads\luma.ipk" root@192.168.1.100:/tmp/luma.ipk
ssh root@192.168.1.100

Trong shell root trên TV (dấu nhắc thường là root@LGwebOSTV:~#), chạy:

luna-send -i luna://com.webos.appInstallService/dev/install \
  '{"id":"com.ecklf.luma","ipkUrl":"/tmp/luma.ipk","subscribe":true}'

Chờ thông báo cài đặt thành công, sau đó mở Luma từ menu TV. Nếu scp không hoạt động, ưu tiên cách cài qua Homebrew Channel ở bước 2.

Bước 4 — Tùy chỉnh Luma

  • Vào Settings → Background → Upload trong Luma để tải ảnh JPEG/PNG/WebP từ điện thoại hoặc máy tính cùng mạng bằng mã QR; chọn vùng cắt 16:9 và lưu.
  • Có thể bật xoay ảnh nền (Rotation), điều chỉnh gradient và sắp xếp ứng dụng theo nhu cầu.
  • Thử mở/đóng ứng dụng và điều hướng bằng remote trước khi bật tự khởi động.

Bước 5 — Chọn cách mở Luma khi bật TV

Phương án A — Autostart (ít can thiệp hơn): Luma tự mở khoảng 25 giây sau khi TV cold boot, không thay chức năng nút Home. Chạy các lệnh sau trong shell root của TV:

sh /media/developer/apps/usr/palm/applications/com.ecklf.luma/autostart.sh enable

Để tắt tự khởi động:

sh /media/developer/apps/usr/palm/applications/com.ecklf.luma/autostart.sh disable

Phương án B — Home takeover (nâng cao): Theo README của Luma, hiện hỗ trợ trên webOS 5, 6, 25 và 26, tùy model. Cách này tạm thời ghi đè cách khởi chạy LG Home, không xóa ứng dụng LG Home gốc. Chỉ bật sau khi đã xác nhận Luma mở bình thường; vô hiệu hóa các ánh xạ nút Home của LG Input Hook hoặc launcher khác trước khi thực hiện.

APP=/media/developer/apps/usr/palm/applications/com.ecklf.luma
sh "$APP/autostart.sh" disable
sh "$APP/home.sh" enable

Kiểm tra trạng thái hoặc khôi phục LG Home:

sh /var/lib/luma-home/home.sh status
sh /var/lib/luma-home/home.sh disable

Quan trọng: Tắt takeover trước khi gỡ cài đặt Luma. Khởi động lại TV để kiểm tra. Log khởi động (nếu cần chẩn đoán): /var/lib/luma-home/boot.log.

Bước 6 — Phương án nút bấm bằng LG Input Hook (tùy chọn)

Nếu không muốn takeover, có thể cài LG Input Hook rồi tạo hành động Execute cho một nút dự phòng, sử dụng lệnh sau. Thử nút khác trước khi ánh xạ Home:

/usr/bin/luna-send -n 1 -w 5000 luna://com.webos.service.applicationmanager/launch '{"id":"com.ecklf.luma"}'

Để khôi phục hành vi nút bấm, xóa ánh xạ tương ứng trong LG Input Hook.

Lưu ý tương thích: Trên webOS 26, README Luma yêu cầu Homebrew Channel 0.8.0-rc1 trở lên cho mapping lunabus.query. Nếu bạn vẫn dùng Homebrew Channel 0.7.3, hãy kiểm tra tương thích trước khi cài Luma. Không nâng cấp hoặc thay thế LG Home một cách mù quáng.
