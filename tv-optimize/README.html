Dọn và tối ưu LG webOS TV

Bớt quảng cáo, bớt dịch vụ chạy ngầm, trả lại RAM cho TV. Phần A chỉnh trong Cài đặt của TV bằng remote, ai cũng làm được. Phần B dành cho TV đã root: script tvopt.sh, một file chạy thẳng trên TV và tự chạy lại mỗi lần bật TV. Nên làm trước khi cài Nobi Launcher.

Chuẩn bị script

Phần A không cần tải gì. Với Phần B, tải tvopt.sh (khoảng 9 KB) vào thư mục Downloads trên máy tính, rồi nhập IP TV trong biểu mẫu phía dưới để tạo lệnh cài đặt.

⤓ Tải tvopt.sh↗ Thư mục trên GitHub

Nếu mở trang này từ GitHub, mở file tvopt.sh trong thư mục tv-optimize rồi chọn Download raw file. Script chạy trên TV bằng tài khoản root, không chạy trực tiếp trên macOS/Windows.

Script chỉ dùng lệnh có sẵn trên TV và tính năng của Homebrew Channel; không tải thêm gì từ Internet.

⚙️ Tùy chỉnh thông tin — lệnh tự cập nhật

Nhập IP TV. Tất cả các khối lệnh phía dưới sẽ tự động thay đổi; chọn tab macOS / Windows để xem lệnh tương ứng.

Xem trong Settings › Network của TV
✓ Lệnh bên dưới được cập nhật tự động

Thông tin cấu hình chỉ dùng để tạo lệnh trong trình duyệt; không gửi lên máy chủ. Luôn kiểm tra lệnh trước khi sao chép và chạy.

⚠ Cảnh báo: Script mới được thử trên LG UK6340PTF, webOS TV Lite 4.4.3. Script không ghi vào phân vùng hệ thống: mọi thay đổi nằm trong RAM hoặc là cờ của Homebrew Channel, nên gỡ hook rồi khởi động lại là TV trở về như cũ (xem Gỡ cài đặt). Trên TV khác, chạy status trước để xem TV có gì.
Không tìm thấy nội dung phù hợp.

2. Phần A: tối ưu không cần root

Mở Settings → All Settings trên TV. Tên mục có thể khác chút tùy vùng và phiên bản.

3. Phần B: yêu cầu

  • TV đã root, có Homebrew Channel chạy ở chế độ root. Cách root: xem hướng dẫn SSH, Root & Homebrew trong repo này, hoặc rootmy.tv và webosbrew.org.
  • Vào được shell root: bật SSH Server trong Settings của Homebrew Channel. Kiểm tra từ máy tính:
ssh root@192.168.1.100 'id'

Kết quả có uid=0(root) là được.

4. Cài tvopt

Bước 1. Chép script lên TV

Chạy trên máy tính, trong thư mục chứa tvopt.sh. Lệnh bỏ ký tự xuống dòng kiểu Windows (CRLF) khi chép, nên dùng được cả khi file bị trình soạn thảo trên Windows đổi định dạng.

Chép tvopt.sh lên TV
cd ~/Downloads
ssh root@192.168.1.100 "tr -d '\r' > /tmp/tvopt.sh" < tvopt.sh
cd "$env:USERPROFILE\Downloads"
cmd /c "ssh root@192.168.1.100 `"tr -d '\r' > /tmp/tvopt.sh`" < tvopt.sh"

Dùng cmd /c vì PowerShell không có toán tử < để chuyển file vào lệnh. Cần OpenSSH Client (Settings → Apps → Optional features).

Bước 2. Cài và áp dụng

ssh root@192.168.1.100 sh /tmp/tvopt.sh install

Lệnh install làm 4 việc, mất 10–20 giây:

  1. Chép script vào /home/root/tvopt/tvopt.sh.
  2. Tạo file cấu hình /home/root/tvopt/tvopt.conf. Cài lại thì cấu hình cũ được giữ.
  3. Tạo hook khởi động /var/lib/webosbrew/init.d/90tvopt, để script tự chạy mỗi lần bật TV.
  4. Áp dụng ngay, không cần khởi động lại.

Bước 3. Kiểm tra

ssh root@192.168.1.100 sh /home/root/tvopt/tvopt.sh status

Kết quả mẫu:

webOS:            4.4.3
Hook khởi động:   đã cài
Telnet root:      tắt
Chặn cập nhật:    bật
Tên miền đã chặn: 13
AirPlay/HomeKit:  không chạy
App đang chạy:    com.nobi.launcher
MemAvailable:     340 MB

Không có máy tính có ssh: mở shell root trên TV (telnet cổng 23 nếu chưa tắt), gõ cat > /tmp/tvopt.sh, dán nội dung file, bấm Ctrl+D, rồi chạy sh /tmp/tvopt.sh install.

5. Các lệnh

Chạy trong shell root trên TV (dấu nhắc thường là root@LGwebOSTV:~#), hoặc từ máy tính bằng ssh root@192.168.1.100 '<lệnh>'.

LệnhLàm gì
sh /home/root/tvopt/tvopt.sh statusXem từng mục đang bật hay tắt, app đang chạy, RAM, 8 dòng log cuối.
sh /home/root/tvopt/tvopt.sh applyÁp dụng lại ngay sau khi sửa tvopt.conf.
sh /home/root/tvopt/tvopt.sh uninstallGỡ hook, bỏ chặn quảng cáo, xoá /home/root/tvopt. Thêm --telnet để bật lại telnet.
cat /tmp/tvopt.logLog của lần khởi động này.

6. Script làm gì

Mỗi mục bật hoặc tắt trong /home/root/tvopt/tvopt.conf (1 = bật, 0 = tắt). Cột cuối là lệnh tương đương nếu muốn làm tay.

BiếnMặc địnhLàm gìLệnh làm tay
BLOCK_ADS1Chặn 13 tên miền quảng cáo LG. Thêm tên miền riêng vào /home/root/tvopt/ads-hosts.txt, mỗi dòng một tên.cp /etc/hosts /tmp/hosts && mount --bind /tmp/hosts /etc/hosts, rồi thêm 0.0.0.0 ad.lgsmartad.com… vào /etc/hosts
BLOCK_TELEMETRY0Chặn thêm 3 tên miền báo lỗi và thống kê. Chưa thử trên webOS 4.Như trên với rdx2.lgtvsdp.com, rdx2.nextlgsdp.com, rdl.lgtvcommon.com
BLOCK_UPDATES1Chặn cập nhật firmware để giữ root. Là công tắc Block system updates của Homebrew Channel, có hiệu lực từ lần khởi động sau.touch /var/luna/preferences/webosbrew_block_updates
DISABLE_TELNET1Tắt telnet root không mật khẩu ở cổng 23: ai trong mạng LAN cũng vào được. SSH vẫn dùng bình thường.touch /var/luna/preferences/webosbrew_telnet_disabled; killall telnetd

PRELOADED_APPSnetflix youtube.leanback.v4Danh sách app id cần đóng. Xem app id đang chạy bằng lệnh status.—
BOOT_DELAY90Số giây chờ sau khi bật TV rồi mới tắt AirPlay, đóng app.—
INTERVAL900Số giây giữa hai lần kiểm app nạp sẵn; 0 = chỉ kiểm lúc bật TV.—

Lệnh đọc trạng thái

Script dùng các lệnh dưới để biết app nào đang chạy, đang hiển thị, đang phát video. Có thể chạy tay để kiểm:

luna-send -n 1 luna://com.webos.applicationManager/running '{}'
luna-send -n 1 luna://com.webos.applicationManager/getForegroundAppInfo '{}'
luna-send -n 1 luna://com.webos.media/getActivePipelines '{}'

Trên một số TV, luna-send -n 1 không in kết quả khi đầu ra đi qua pipe. Khi đó dùng luna-send -i … rồi bấm Ctrl+C; script đã tự xử lý việc này.

7. Đổi cấu hình

Ví dụ giữ AirPlay để chiếu từ iPhone. Chạy trên TV:

sed -i 's/^DISABLE_AIRPLAY=1/DISABLE_AIRPLAY=0/' /home/root/tvopt/tvopt.conf
sh /home/root/tvopt/tvopt.sh apply

Mục đã tắt trong lần chạy trước (AirPlay, app nạp sẵn) chỉ chạy lại sau khi khởi động lại TV. Muốn sửa nhiều mục, mở file bằng vi /home/root/tvopt/tvopt.conf.

8. Gỡ cài đặt

ssh root@192.168.1.100 sh /home/root/tvopt/tvopt.sh uninstall
  • Script không ghi vào phân vùng hệ thống. /etc/hosts là bản trong RAM (bind mount); AirPlay và app nạp sẵn chỉ bị tắt tới lần khởi động sau. Gỡ xong, khởi động lại là TV trở về như cũ.
  • Thêm --telnet để bật lại telnet root từ lần khởi động sau.
  • uninstall giữ nguyên cờ chặn cập nhật firmware; bỏ cờ này trong Settings của Homebrew Channel nếu muốn.
  • Nếu TV lỗi lúc khởi động, chế độ failsafe của Homebrew Channel tự bỏ qua các hook ở lần sau.

10. Giới hạn và nguồn

Giới hạn

  • Chỉ thử trên webOS TV Lite 4.4.3. Máy webOS 5 trở lên dùng chung cách gọi Luna nhưng app id của YouTube, tên dịch vụ AirPlay có thể khác. Chạy status trước để xem app id thật, rồi sửa PRELOADED_APPS.
  • Chặn bằng /etc/hosts không chặn được tên miền con theo vùng (ví dụ eic., aic.) hay IP ghi cứng trong firmware. Muốn chặn rộng hơn, dùng DNS hoặc Pi-hole như mục 8 của Phần A.
  • Bỏ qua app đang phát video cần node trên TV (webOS có sẵn). Không có node thì script chỉ bỏ qua app đang hiển thị.

Nguồn

  • Cờ và hook của Homebrew Channel: webosbrew/webos-homebrew-channel services/startup.sh.
  • Nhóm tên miền và tác dụng phụ khi chặn: Level1Techs — LG TV Block Mini-How-to, hugobatista/lg-tv-ad-block.
